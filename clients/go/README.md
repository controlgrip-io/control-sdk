# ControlGrip client — see the [root README](../../README.md) for the shared surface and quickstart.

GitHub App methods are available as `GitHubStatus`, `ConnectGitHub`,
`DisconnectGitHub`, `GitHubRepositories`, `GitHubBranches`, and
`GitHubRepositoryFileExists`. `ConnectGitHub` returns a URL that must be opened
in a browser to complete GitHub authorization and App installation.
